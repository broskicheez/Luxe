# Luxe - Dark Theme Android App

🌙 **Мрачная темная тема с красивыми волнистыми паттернами**

## Описание
Люксовое Android приложение с:
- ✨ Темная мрачная красивая тема
- 🌊 Анимированные волнистые паттерны
- 💜 Фиолетовые, синие и киберпанк цвета
- 🎨 Material Design 3
- ⚡ Jetpack Compose для современного UI
- 🎭 Гладкие анимации и переходы
- 📱 Красивое меню

## Как скомпилировать в APK

### Требования:
- Android Studio (последняя версия)
- JDK 11 или выше
- Gradle 8.1+

### Шаги для создания APK:

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/broskicheez/Luxe.git
cd Luxe
```

2. **Откройте в Android Studio:**
   - Запустите Android Studio
   - File → Open → выберите папку Luxe
   - Дождитесь синхронизации Gradle

3. **Соберите Debug APK:**
```bash
./gradlew assembleDebug
```

APK файл будет находиться в:
```
app/build/outputs/apk/debug/app-debug.apk
```

4. **Соберите Release APK:**
```bash
./gradlew assembleRelease
```

Release APK файл:
```
app/build/outputs/apk/release/app-release.apk
```

### Установка на телефон:

**Через Android Studio:**
- Подключите телефон через USB
- Нажмите Shift+F10 или Run → Run 'app'

**Через командную строку:**
```bash
adb install app/build/outputs/apk/debug/app-debug.apk
```

**Через интерфейс:**
- Просто скопируйте APK файл на телефон
- Откройте файловый менеджер на телефоне
- Нажмите на APK файл → Install
